# Shivam Jewels - 80th Independence Day WebAR Experience

This project houses the WebAR interactive invitation card experience for Shivam Jewels, celebrating 80 Years of Freedom.

## Important Project Notes

- **Scanner Overlay**: The camera scan screen features a transparent blueprint wireframe outline representing the printed invitation card layout to guide physical card alignment.
- **Rays & Star Mapping Guides**: In accordance with design requirements, **we are currently not using scanning rays, concentric star guides, or stardust ray animations in the project, as they are not needed.**
- **Developer Bypass Preview**: A developer HUD panel allows direct WebGL 3D preview checking ("Bypass Scan") and links to the Shivam Jewels homepage ("SJWorld Website").
